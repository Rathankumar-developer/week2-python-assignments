# Week 2 – Data Structures & File Handling

Python assignments and mini project covering Lists, Tuples, Dictionaries, File I/O, and JSON.

## Files

| File | Description |
|---|---|
| `contact_book.py` | Assignment 1 – Contact Book using a dictionary (add, search, update, delete). |
| `word_counter.py` | Assignment 2 – Counts words, lines, and characters in a text file. |
| `json_reader.py` | Assignment 3 – Loads JSON data and prints it in a readable, formatted way. |
| `student_management_system.py` | Mini Project – Student Management System storing records in a CSV file (add/delete/search, saved permanently). |

## How to run

Each script is standalone and runs with:

```bash
python3 contact_book.py
python3 word_counter.py
python3 json_reader.py
python3 student_management_system.py
```

All scripts use only the Python standard library (`json`, `csv`, `os`) — no extra installs needed.

## Skills demonstrated

- Lists, tuples, sets, dictionaries
- Reading/writing text files
- Working with CSV and JSON
- Exception handling
- Basic CRUD logic and persistent file storage
